# Norman Groupies — CS6750 Prototypes

Two standalone HTML concept prototypes for the project **Scheduling Meetings Across Time Zones**.

## Files

- `index.html` — simple landing page linking to both prototypes. GitHub Pages uses this as the site's home page.
- `smart-meeting-time-finder.html` — Smart Meeting Time Finder (Concept 01).
- `visual-availability-timeline.html` — Visual Availability Timeline (Concept 03).

## Run locally

No installation, framework, or build step is required. Download or clone this repository, then open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `norman-groupies-prototypes`).
2. Upload all three HTML files and this README to the repository's **root** directory.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes publishing, share the URL shown in the Pages settings with your teammates.

## Important prototype notes

These are early interactive mockups using illustrative sample participants, time zones, availability, and scores. They do not connect to calendars, store user submissions, or calculate real availability. The time-zone offsets shown are examples and should not be treated as date-aware conversions, especially around daylight saving changes.
